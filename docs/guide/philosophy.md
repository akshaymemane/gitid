# Project Philosophy

GitID is built around confidence.

The problem is not that Git lacks identity features. The problem is that the features are spread across tools and files:

- global and local Git config
- SSH keys and host aliases
- GitHub CLI authentication
- project folders
- shell startup files

GitID gives those pieces one profile-oriented workflow.

## What GitID Is

- lightweight
- terminal-native
- local-first
- safe by default
- easy to explain

## What GitID Is Not

- a secrets manager
- a hosted account sync service
- an enterprise IAM product
- a Git GUI

GitID should feel like a practical developer tool: fast enough to use every day, boring enough to trust, and clear enough that a new teammate can understand it quickly.
