# `gitid list` And `gitid current`

## `gitid list`

List saved profiles.

```bash
gitid list
```

Alias:

```bash
gitid ls
```

The table shows:

- active profile marker
- profile name
- Git name and email
- GitHub username
- whether an SSH key is configured

## `gitid current`

Show the active GitID profile and current Git identity.

```bash
gitid current
```

Alias:

```bash
gitid status
```

Use this before committing if you want a quick confidence check.
